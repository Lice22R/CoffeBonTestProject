# CoffeBon Test Project

An educational coffee shop website built with standalone HTML, CSS, and JavaScript.

## GitHub Pages

Publish the `main` branch from `/ (root)` in repository Settings → Pages.

Expected URL: https://lice22r.github.io/CoffeBonTestProject/

Telegram bot: https://t.me/CoffeBonBot

## Demo behavior

Orders and club membership are stored in the visitor's browser only.
The website and Telegram bot do not share orders or bonus balances.
Prices, club rules, hours, and shop tags follow the supplied educational prototype.
No real orders or payments are processed.

Python bot hosting is separate from GitHub Pages. Bot credentials and databases
must remain outside this repository.
